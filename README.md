## About the project- GUESS THE NUMBER GAME

A simple fun game where the user has to guess a randomly generated number from a specified range. When the code is run the user will be prompted to write their guesses in the terminal and will get 7 guesses to get the correct number between 1-50 for this game. They will be informed if their guess is too low, too high or correct. they can then repeat the game if they want to.
